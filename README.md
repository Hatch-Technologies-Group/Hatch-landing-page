# Hatch Landing Page

A modern landing page with particle background effects and an interactive pricing configurator built with TailwindCSS.

## Live Demo

https://hatch-technologies-group.github.io/Hatch-landing-page/

## Features

- Particle.js animated background
- Responsive design with TailwindCSS
- Interactive pricing configurator
- Modern UI components

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Hatch-Technologies-Group/Hatch-landing-page.git
cd Hatch-landing-page
```

2. Install dependencies:
```bash
npm install
```

### Running the Project

#### Development Mode
Run with auto-reload for CSS changes:
```bash
npm run dev
```

#### Production Build
Build minified CSS:
```bash
npm run build
```

#### View the Page
Open `index.html` in your browser to view the landing page.

- HTML5
